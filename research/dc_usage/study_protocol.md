# 디시 온라인 언어 전반 조사 설계: 허가된 자료를 확보했을 때

이 문서는 **아직 수행하지 않은 본 조사** 계획이다. 지금까지 수행한 검색 색인 기반 편의표본 41건을 디시 전체의 '전수조사'나 '대표표본'이라고 부르지 않는다.

## 수집·저작권·개인정보 원칙

디시인사이드 이용약관은 사전 서면 동의 없는 사이트 크롤링을 제한한다.
공식 허가 또는 합법적으로 분석 가능한 데이터 제공 계약을 확보하기 전까지 댓글 API 호출·페이지 대량 수집·우회 접근을 개발하지 않는다.
데이터를 확보했더라도 닉네임, 아이피, 사진, 회원 식별정보, 민감한 사연은 불필요하게 보존하지 않는다.

## 조사 기간

2024-11-24부터 2026-11-24. 초기 2024Q4와 마지막 2026Q4는 일부 기간만 포함한다.
이 두 기간은 다른 분기와 원시 건수를 곧바로 비교하면 불공평하다.

## 층화 축

1. **갤러리 규모/형태:** 메이저, 마이너, 미니; 인기 게시글과 일반 게시글을 구분
2. **주제:** 게임·e스포츠, 대중음악·아이돌, 스포츠, 패션·뷰티, IT·AI, 음식·여행, 일상·직장, 학교·수험, 취미·서브컬처, 사회 이슈
3. **기간:** 2024년 말에서 2026년 11월까지 분기 단위, 가능하면 월 단위
4. **본문 위치:** 제목, 본문, 댓글, 댓글에 대한 답글
5. **화행:** 칭찬, 비판, 자기비하, 공격적 도발, 반어적 칭찬, 동의 요청, 규범 경고, 정보 질문, 팬덤 인용, 중립적 은어
6. **표현 종류:** 유행 신조어, 오래된 정착어, 밈 인용, 문장 종결 방식, 제목 형식, 이모티콘/초성, 사진·영상 의존 밈
7. **선택 편향:** 추천순/신규순, 사용자가 정한 검색어 포함 여부, 삭제된 글·검색 미색인 글 여부

## 확인해야 할 실제 질문

- 이 표현이 누군가의 취향이나 품질을 평가하는가, 감정을 터뜨리는가, 상대를 자극하는가?
- 대상을 명확히 지칭하는가? 인물·작품·아이템·갤러리 운영자 중 누구인가?
- 남을 놀리는가, 자신을 놀리는가? 비꼬는가, 진짜 칭찬인가?
- 같은 단어가 다른 분야의 갤러리에서 의미가 달라지는가?
- 발화가 사진·동영상·게임 패치·이전 댓글을 알아야 이해되는가?
- 언제부터 나타났으며, 이 기간의 어느 분기에 실제 사용 증거가 남아 있는가?
- 일부 이용자만 쓰는 은어인가, 여러 주제에서 쓰이는가?
- 더 이상 거의 쓰이지 않는 표현인지 판단할 충분한 시계열 증거가 있는가?

## 근거의 단계

- **A:** 날짜가 확인되는 게시글 본문/댓글과 앞뒤 반응을 직접 검토, 원문 재배포 권리 확인
- **B:** 날짜·제목·본문 일부가 검색 색인에서 확인되지만 댓글·전체 맥락을 보지 못함
- **C:** 신조어 사전이나 기사에서 사용법 소개만 확인
- **D:** 사전의 이름·연도 등 메타데이터만 있는 후보

현재 41개 디시 사례는 A에 가까운 본문 확인 13건과 B 수준 28건. 댓글 전체 검토 사례는 0건.

## 분석 단계

1. 출처별 권한·로봇 정책·수집 규모·원문 저장 가능 여부 문서화
2. 허가된 데이터에서 날짜·갤러리·제목/본문/댓글을 추출해 분기별 사용량 집계
3. 짧은 문맥과 해당 부모 글·이전 댓글을 검토하는 라벨링 절차 마련
4. 서로 다른 검토자가 최소 일부 사례를 이중 라벨링해 합치도·논쟁 항목 기록
5. 유사한 소리의 중의어(긁혔/밤티/느좋/딸깍 등)를 별도 보류 또는 재검토
6. 사용 빈도와 글쓰기 적용 적합성을 별도 지표로 평가
7. 최근 사용이 사라진 표현은 자동으로 폐기하지 않고 사용 맥락과 최신 증거를 갱신
