# 복합 맥락 해석: 분류표가 아니라 인과 지도로 활용

## 원칙

맥락은 글 끝에 체크하는 장식이 아니다. **그 맥락이 달랐다면 화자의 판단·감정·어휘·생략 가운데 무엇이 달라졌는가?**라는 질문을 통과해야 한다. 한 가지도 바꾸지 않는 지식은 배경으로만 보관한다. 실제 원고에는 필요한 것만 남긴다.

## 살펴볼 맥락

| 층위 | 결정적 질문 | 문장에 미치는 흔적 |
|---|---|---|
| 사회 | 어떤 행동이 이 공동체에서 예의·책임·부당함인가 | '부탁'과 '떠넘김'의 기준 |
| 문화·세대 | 매체/집단마다 무엇이 암묵적으로 통하나 | 설명할지 생략할지, 높임과 농담 |
| 관계·권한 | 누가 누구에게 요청하고 거절할 수 있나 | 완곡함, 불만의 대상, 반응 선택 |
| 상황 | 장소·긴급성·대안·동시에 진행되는 일은 | 그때 행동이 합리적인지 |
| 시간·누적 | 처음인가 반복인가, 앞선 약속은 | '또', '이제 와서', 감정의 강도 |
| 경험 | 무엇을 직접 겪었고 무엇을 전해 들었나 | 직접 관찰과 추측 분리 |
| 심리·정서 | 기대·침해·불안·보상·상실이 어떻게 작용하나 | 감정의 이유를 단어나 장면에 담음 |
| 가치관·성향 | 무엇에 민감하며 무엇을 용인하는가 | 같은 사건의 다른 판단 초점 |
| 인지·지식 | 화자가 그 순간 아는 것과 나중에 안 것은 | '그땐 몰랐다'의 시점 일관성 |
| 대화·공통기반 | 말하기 전 서로 아는 정보는 | '잖아'·생략·반문 가능성 |
| 독자·이해관계 | 글을 읽는 사람이 무엇을 걸고 있나 | 정보 공개 순서·예시 선택 |
| 매체·목적 | 정보 검색인가, 하소연인가, 비평인가 | 속도·어미·증거·후킹 형태 |
| 인식·근거 | 확인된 것/주장/해석/허구의 경계 | 단정·인용·조건문 선택 |

## 구체적인 반사실 테스트

공통 입력: 밤 11시에 상사가 업무 메시지를 보냈다.

- **긴급** 당직 중 환자 급변: 밤 자체만으로 부당하다고 못함. "굳이"를 붙이기 어렵다.
- **비긴급·첫 연락**: "이걸 굳이 지금?"의 근거는 생길 수 있으나 "또"는 쓰지 않는다.
- **비긴급·반복·익일 질책**: 휴식 중에도 답해야 한다는 압박을 읽을 단서가 생긴다.
- **동료끼리 사전 합의**: 똑같이 밤 연락이어도 책임 평가가 달라진다.

이 네 버전의 문장이 차이가 없다면 맥락 해석에 실패했다. 이 장면은 **훈련용 가상 설정**이며 사용자 실제 경험인 것처럼 쓰면 안 된다.

## 역방향 검사

완성 원고에서 '또', '굳이', '하필', '어차피', '꼭', '잖아', '조차', '마저'를 찾는다. 각각이 암시하는 과거·대안·공통지식이 자료에 있는가? 맥락 없이 생긴 감정 표시는 잘라내되, 이유가 실제로 있으면 표현도 살린다.
