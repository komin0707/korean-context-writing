# 프롬프트 추가 전에 원인을 찾는 대조 실험

기존 main과 이전 실험 스킬을 수정하지 않고 **같은 주제·같은 사실 자료·같은 모델**로 비교한다. 현재 나온 실패 원인을 어느 지침 탓이라고 단정하지 않는다.

이 실험은 세 가지 집필 조건을 준비한다.

- **A — v2.1:** 기존 main 커밋의 스킬/작성 프롬프트/프로필을 그대로 사용
- **B — 최신 실험:** experiment/no-forced-turns까지 반영된 집필 프롬프트와 실제 승인 발췌 사용
- **C — 성공 사례 분석·발췌를 빼기:** B에서 실제 예시 인용과 그 해설 블록만 제외. 나머지 현재 지침을 유지. 일부 공통 지침에는 여전히 관련 개념이 남아 있으므로 완전한 단일변수 제거 실험은 아님

B의 원고만 추가로 **삭제 중심 편집(D)**에 넣는다. 기존 리뷰어의 6개 점수→자동 재작성 방식 대신, 새 문장을 창작하지 않고 중복 표현을 잘라내는지 비교한다. D는 새 집필본이 아니므로 A/B/C와 같은 조건으로 생성됐다고 취급하지 않는다.

## 실행

python3 experiments/ablation/run.py --case 01_운동_편의점 --output /tmp/writing-ablation

위 명령은 프롬프트만 준비한다. 생성 모델은 호출하지 않는다. --model-cmd로 **stdin으로 프롬프트를 받으며 stdout으로 결과를 반환하는 실제 모델 CLI**를 설정하면 A/B/C 원고와 B의 삭제 편집본을 생성한다.

python3 experiments/ablation/run.py --case 01_운동_편의점 --output /tmp/writing-ablation --model-cmd 'YOUR_STDIN_MODEL_WRAPPER' --samples 3

각 조건은 별도 프로세스 호출이며 동일한 모델 설정·입력을 사용한다. 생성 모델의 비결정성 때문에 여러 번 반복해 비교하는 게 좋다.

판정할 때는 어떤 조건인지 가리고 세 가지를 본다.

1. **새 관찰:** 문단을 하나 더 읽고 실제로 새롭게 알거나 웃을 것이 생겼는가?
2. **중복:** 앞서 한 말을 다른 비유로만 또 이야기하는 문단이 있는가?
3. **말투와 사실:** 억지 자기반성·허구 경험·과장된 논문 해설이 생겼는가? 사실은 틀리지 않았는가?

**최소 채택 기준:** 서로 다른 소재 3개에서 이전보다 중복 문단이 줄고, 화자의 생생함이 좋아졌다는 사람이 직접 보는 평가가 필요하다. 수치 점수나 구조 테스트만으로 승인하지 않는다. 이 실험이 실패하면 또 문체 규칙을 쌓지 말고 잘 나오는 조건을 찾아 그 조건을 기준으로 삼는다.

각 프롬프트를 여러 번 독립 실행하는 이유는 **비유·화자의 태도·시선이 실제로 다르게 나오는 초안 중 좋은 걸 고르기 위해서**다. 3개 원고를 하나로 합치거나 모델에게 '더 큰 반전'을 요구하지 않는다. 우수한 초안이 이미 짧고 완결됐으면 편집 D는 적용하지 않아도 된다. 최종 선택은 사용자가 한다.
