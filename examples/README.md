# 문체 표본의 신뢰 수준

이 자료는 '자연스러운 한국어'를 완벽하게 가르치는 완성된 인간 평가 데이터가 아니다. **승인 상태를 섞지 않고 불필요한 학습 오류를 줄이기 위한 저장소**다.

- `approved.jsonl`: 사용자가 실제 목표 수준으로 지목한 발췌는 status=approved로, 이전의 부분 평가 사례는 별도 상태로 구분한다. 발췌 승인이지 전체 글의 사실관계 승인이나 모든 장르에 동일 문구를 적용하라는 뜻은 아니다.
- `partial.jsonl`: 어느 정도 괜찮았지만 핵심 결함이 남았다는 명시적 피드백.
- `rejected.jsonl`: 실제 실패 문장과 실패 이유. '이 문장을 써라'는 예시가 아니다.
- `rejected_articles/`: 테스트에서 실패한 실제 원고의 전체 맥락. 다른 모델의 독자적 작성 결과를 승인된 문체처럼 재학습하지 않는다.

실제로 채택한 인간 작가의 표본은 **현재 매우 제한적**이다. 모델이 만든 새 글을 임의로 `approved`로 이동시키면 안 된다. 사용자의 구체적 긍정 피드백이 있거나 지정된 평가자가 명시적으로 승인한 경우만 새 레코드를 추가한다. 제삼자 저작물은 권한과 인용 범위를 준수해 짧은 연구용 발췌 또는 링크로 관리한다.

테스트 용도로 생성된 예문은 `approved`가 아니다. 여러 장르에 대응할 충분한 승인 사례가 없을 경우 결과는 '임시 평가'이며, 완성된 스타일 모델로 보고하지 않는다.
