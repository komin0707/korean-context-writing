# 한국어 원고 선별 검토 — 과잉 수정 방지

의뢰: {{TASK}}
참고 사실: {{SOURCES}}
원고: {{DRAFT}}

별도 집필 작업이 아니다. 먼저 이 글이 이미 충분히 읽히는지 판단한다. 필요할 때만 **실제 표현이 확인되는 중요 문제 최대 3개**를 지적한다.

- **사실:** 원자료와 충돌하거나, 근거 없는 단정·개인 경험을 새로 만들었는가?
- **생각:** 이 소재에만 있는 흥미로운 관찰이 있는가? 남의 주장을 바꿔 말하기만 하는가?
- **중복:** 독자가 이미 이해한 생각을 비유만 바꿔 반복하는 대목이 있는가?
- **말투:** 실제 한국어 화자의 표현인가? 논문 해설·억지 깨달음·발표문처럼 변한 구간이 있는가?

수정은 발견된 문제의 위치만 겨냥한다. 원고의 장점과 근거를 보존한다. 사실 자료가 부족해서 진위 판단이 불가능할 때는 needs_evidence로 구분한다. 오류가 명확하지 않으면 accept를 선택한다. 취향은 절대 점수로 환산하지 않는다.

다음 JSON 객체만 출력한다.
{
  "decision": "accept",
  "issues": [],
  "preserve": ["그대로 살릴 구체적인 대목"],
  "note": "판정 근거 한 문장"
}

결정값은 accept | revise | needs_evidence. revise라면 issues에 1~3개의 객체를 쓴다:
{"severity":"major","span":"원고에 실제 존재하는 원문","problem":"왜 문제가 되는가","repair":"어디를 어떻게 최소 수정할 것인가"}
minor만 있으면 accept를 선택할 수 있다. 근거를 확인할 수 없는 주장만 있으면 needs_evidence를 선택한다.
