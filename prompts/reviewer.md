# 한국어 원고 편집 평가

의뢰: {{TASK}}
근거: {{SOURCES}}
승인된 문체 참고: {{STYLE_REFERENCES}}
원고: {{DRAFT}}

원고의 실제 문장을 인용하여 평가한다.

1. 맥락(context): 관계·시간·경험·사회적 기준이 필자의 판단에 실제로 반영됐는가.
2. 관점(stance): 화자의 고유한 가치 기준과 하고 싶은 말이 선명한가.
3. 말투(voice): 익숙한 한국어 어휘·연어·어미·말의 호흡으로 한 사람이 말하는 느낌이 나는가.
4. 공감(empathy): 감정이 생기는 이유와 독자가 떠올릴 장면이 살아 있는가.
5. 흡인력(hook): 이 소재에서만 가능한 새롭고 날카로운 관찰이 있는가. 독자가 친구에게 보내고 싶거나 반박하고 싶은 구체적인 한마디가 있는가. 사건과 감정이 힘 있게 이어지고 설명의 분량이 재미와 이해에 실제로 기여하는가.
6. 사실(truthfulness): 연구 근거·수치·적용 범위의 표현이 확인된 자료와 맞는가.

구체적으로 다듬을 문장을 고르고, 같은 의미를 더 흥미롭고 자연스럽게 전달할 긍정형 편집 행동을 제안한다. 좋은 문장과 근거는 보존한다.

JSON으로 출력:
{
  "decision": "revise",
  "scores": {"context": 0, "stance": 0, "voice": 0, "empathy": 0, "hook": 0, "truthfulness": 0},
  "issues": [
    {"severity": "major", "span": "원고에 실제 있는 표현", "problem": "현재 표현에 대한 구체적인 평가", "repair": "실행할 긍정형 수정 방향"}
  ],
  "what_to_preserve": ["확인된 강점"],
  "revision_priority": "가장 중요한 개선 동작"
}

각 점수는 0~3 정수다. 정확한 근거가 필요하면 decision에 needs_evidence, 편집을 진행하려면 revise, 충분히 좋으면 provisional을 사용한다. 모델의 평가는 사용자 승인과 별도로 취급한다.
