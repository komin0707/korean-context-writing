## 편집 기준

원고의 실제 문장을 근거로 다음 항목을 평가한다.

1. 맥락: 화자의 판단을 만든 사회·문화·관계·경험·시간 조건이 글의 의미와 표현에 살아 있는가.
2. 관점: 글쓴이가 왜 이 주제를 꺼내는지, 어떤 사실을 중요하게 보는지 읽히는가.
3. 말투: 실제 한국어에서 자연스럽게 쓰는 어휘와 연어, 주어·동사의 관계, 조사·어미에 깔린 전제, 사회적 말투와 앞뒤 문장의 이어짐을 살핀다. 문단 안에서 각 문장이 전달·평가·연결·질문 중 어떤 역할을 하는지와 그에 따른 종결·길이·호흡을 함께 판단한다. 원고에서 선택한 표현이 독자에게 어떤 뜻과 감정으로 들리는지 문장 단위로 설명한다.
4. 공감: 누가 무엇을 기대하고 무엇을 감당하는지, 관계·책임·선택권·실제 손익을 통해 감정의 이유와 강도가 살아 있는가. 독자가 경험과 관심사에 따라 공감하거나 반박할 만한 근거가 있는가.
5. 후킹: 도입의 관심이 다음 문장으로 이어지고 본문에서 발전하는가.
6. 사실: 근거와 추론의 범위가 정확하며 각 자료가 실제 주장을 뒷받침하는가.

각 평가에는 원고에서 확인한 짧은 표현을 인용한다. 더 선명해질 수 있는 구절을 골라 정확한 개선 행동을 제시한다. 중심 관찰과 확인된 좋은 표현은 보존 대상으로 남긴다.

## JSON 형식

{
  "decision": "revise",
  "scores": {"context": 0, "stance": 0, "voice": 0, "empathy": 0, "hook": 0, "truthfulness": 0},
  "issues": [
    {"severity": "major", "span": "원고의 정확한 일부 문장", "problem": "현재 문장과 원고 맥락에 대한 편집 관찰", "repair": "작성자가 실행할 구체적인 긍정형 개선 방향"}
  ],
  "counterfactual": "맥락 한 가지가 달라지면 표현과 판단이 어떻게 달라질지",
  "what_to_preserve": ["원고에서 살아 있는 관찰과 근거"],
  "revision_priority": "가장 중요한 긍정형 편집 목표",
  "verification_note": "모델 평가로서 실제 사용자 승인과 별도로 관리"
}

점수는 0~3 정수로 기록한다. 모든 핵심 항목에서 충분한 근거가 발견되면 decision을 provisional로 기록한다. 구체적인 편집 개선이 필요한 구절이 있으면 revise로 기록한다. 자료 확인이 필요한 경우 needs_evidence를 사용한다. issues에는 인용한 구절과 개선 방향을 항상 함께 기록한다. 최종적으로 사용자 평가를 따로 받는다.
