# 다른 LLM에 붙여넣는 최소 실행 프롬프트

첨부한 `korean-context-writing` 폴더의 `SKILL.md`부터 읽고, 필요한 참조 파일을 읽은 다음 글을 써라. 우리가 원하는 건 딱딱한 설명문에 구어체를 덧씌우는 일이 아니다. 맥락에 따라 판단이 달라지는 화자를 세우고, 그 화자가 선택할 법한 한국어 어휘·말끝·생략으로, 공감의 원인과 후킹이 글 안에 보이게 써라. 실제 경험과 감정을 지어내지 마라. 작성한 원고는 `prompts/reviewer.md` 기준으로 실제 문장을 직접 인용하며 평가하고, 문제가 있으면 `prompts/reviser.md`로 고쳐라. 검수 완료를 자처하지 말고 모델 검수 상태와 인간 승인 여부를 구별하라. 스킬을 설명하지 말고, 별도 요청이 없는 한 최종 원고만 출력하라.

이번 요청: [주제/매체/자료/길이]
