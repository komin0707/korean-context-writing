# 한국 커뮤니티 표현 참고 자료 v0.1

**범위:** 2024-11~2026-11에 소개되었거나 사용 정황이 확인된 한국 온라인 밈·신조어·댓글 형식. 2024년 이전 출생 표현도 이 기간에 재유행하거나 사용된 경우 기록한다. **모든 표현을 빠짐없이 수집했다는 뜻이 아니다.**

## 무엇이 담겼나

- verified.jsonl — 40개 편집 검토 항목. 명칭, 뜻, 구체적인 사용·회피 상황, 모델이 독자적으로 만든 짧은 예문, 자료가 확인된 월, 출처 ID, 주의 위험, 실제 DC 게시글 표본 여부.
- ../research/sources.json — 출처의 URL, 확인 가능한 발행 시기와 한계.
- ../research/candidates_index.jsonl — 사전에서 2024~2026으로 분류한 159개 **검토 전 후보**. 집필 프롬프트에 직접 사용하지 않음.

**주요 구분:** 최초 발생 연도 ≠ 재유행 시점 ≠ 마지막으로 문서에서 확인한 시기 ≠ 오늘의 사용 빈도. 확인된 날짜만 기입했고 실제 사용량·세대별 빈도는 조사하지 못했다. 2024년 11월에 확인된 항목 중 24일 이전 자료도 있어 엄격한 24개월 이내 첫 사용을 뜻하지 않는다.

## 어떻게 쓰나

1. 최근 말투가 필요한 글에서 주제 관련 항목 최대 3개만 *후보*로 읽는다.
2. 각 항목의 use_when과 avoid_when을 비교해 정말 자연스러운 경우에만 **최대 1개** 실제 원고에 쓴다.
3. 사실 전달이 중요한 의료·법률 글이나 근거 없는 비난에는 사용하지 않는다.
4. 옛 유행을 현재 유행이라고 단정하지 않는다. 최종 유행 시점을 확인하지 못했다면 새 사례를 조사한다.
5. 별도 요청이 없는 원고에는 단어를 억지로 끼워 넣지 않는다. 기본은 그냥 자연스러운 DC 말투다.

직접 조회:

    python3 scripts/select_slang.py --topic "게임 업데이트 운영" --genre community --asof 2026-11
    python3 scripts/select_slang.py --topic "패션 브랜드 로고 디자인" --genre community --asof 2026-11

집필 프롬프트에 유행어 후보를 넣으려면 명시적으로 --slang-context를 지정한다.

## 이후 조사 보강법

새 용어는 별도 기사 목록뿐 아니라 실제 이용자 댓글·게시글과 날짜를 함께 확인한다. 원문 전체를 복사하지 않고 짧은 내용 요약과 URL만 저장한다. 단순한 사전 등재로는 유행을 확인했다고 처리하지 않는다. 1차 사용 예시와 다른 출처가 서로 충돌하면 조사 필요 상태로 둔다.

월별로 미검증 후보를 확인하고, 분기별로 최근 사용 증거가 사라진 표현은 최근 어휘 목록에서 제외하는 것이 바람직하다. 현재 자동 수집·자체 갱신은 실행하지 않는다. 신조어 사전 및 게시글의 이용약관, 공개 가능 범위를 존중한다.

**이것은 개인 기억이 아니라 모두에게 공개 가능한 언어 연구 자료다.**

## 새 후보 갱신

후보 목록을 수동 갱신하려면 프로젝트 루트에서 python3 scripts/refresh_slang_candidates.py --dry-run 으로 확인한 다음 --dry-run 없이 실행한다. 이 작업은 검토된 40개 항목의 뜻이나 날짜를 자동 갱신하지 않는다.
